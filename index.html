Profile Editor

Make the map yours.

  • Profile picture — paste an image URL to set it.
  • Username — enter a new name, then press Save.
  • Topic ID name — give a topic a friendly name in Load.
  • Topic ID to PFP — link a topic to your PFP; pressing it opens that topic in Load.
  • CLICK2LINK — attach any URL to your username.
  • Domain — give a topic a global name so you can also find it by domain.

Load

Find and read any topic.

  • Load messages from a topic ID or a linked domain.
  • Stacked topics (multiple IDs on one domain) load together, with the creator's names.
  • Options — filter by blocked users, a date/time range, or specific users.
×

Create Topic

Start a new space.

  • Create a new topic ID or a new key pair.
  • New topics must be stacked: TOOLBAR → Stack topic IDs.
  • Admins — who can change this topic's rules later. Keep your private key safe to do so.
  • Your keys also power E2EE Chat: public locks messages, private unlocks them.
×

Map Drawing

Place markers and polygons.

  • Draw markers and polygons. Some topics require NFTs — check the topic's Rules.
  • Need a topic? TOOLBAR → Create.
  • Domain/Topic ID — where the shape's data is stored.
  • Number — reference ID to edit or delete the shape later.
  • Coordinates — where the shape sits on the map.
  • Optional settings — cover photo, title, image URL, and popup message when pressed.
  • Delete — remove a shape by its Number and Domain/Topic ID.
×

Topic Rules

Control who can write to your topic.

  • Choose which markers/polygons appear when others search your topic.
  • Rules are tied to a Domain/Topic ID and set in pairs — the last one wins.
  • Pick the required NFT and how many messages each owned NFT allows.
  • Max size — the largest polygon the required NFT can use.
  • Enter a Domain/Topic ID, press Load Topic Rules to read the current rules.
×

Model Sharing & Rules

Share locations with NFT holders.

  • Domain/Topic ID — where the data is stored.
  • Model sharing — choose which NFT holders can share their location (top-right corner).
  • Model size — size multiplier per NFT. Example: VIP NFT at 2× → 2× bigger model.
  • Topic chat — only messages from users with the required NFT are shown.
  • Enter a Domain/Topic ID and press Load Topic Rules to read the current rules.
×

Update Topic

Edit your topic's rules and fees.

  • Domain/Topic ID — the topic to edit.
  • Private key — signs and approves the change.
  • Admins — who can set this topic's rules.
  • Optional fee — make users pay per message posted.
  • Set amount — the fee per message.
  • Token ID — the Hedera token received as payment.
  • Royalty account — where the payments go.
×

Stack Topic IDs

Group topics under one domain.

  • Stack one or more topics under a parent topic.
  • Domain/Topic ID — the parent topic.
  • Topic ID/IDs — one or more topic IDs, comma-separated.
×

Topic Chat

Read and write public messages.

  • Domain/Topic ID — the topic to read and write.
  • Load — fetch its messages.
  • Options — filter by blocked users, a date/time range, or specific users.
  • Go to the top — back to the start of the chat.
  • Submit Message — needs a Domain/Topic ID; max 256 characters.

E2EE Chat

Private, end-to-end encrypted messages.

  • Domain/Topic ID — the topic to read and write.
  • Load — fetches messages; your private key / password unlocks them.
  • Options — filter by blocked users, a date/time range, or specific users.
  • Pin — as admin, pin your public key so only you can unlock messages.
  • Go to the top — back to the start of the chat.
  • Submit Message — needs a Domain/Topic ID; max 256 characters.
