Profile Editor

Make the map yours.

  • Profile picture — upload an image. On markers is the center crop. On polygons is the full picture beside it.
  • Username — enter a new name, then press Save.
  • BIO — set your profile bio; tapping a PFP shows it in Load.
  • CLICK2LINK — attach any URL to your username.
  • Your topic — the topic connected to this account. Share posts land here. Followers follow this topic. Connect saves the topic id. The × next to a connected id takes that connection off.
  • Public key — pin your Ed25519 public key to your connected topic. Anyone can then send you an encrypted message just by your payer id.
  • Preview — the card updates as you change the picture, name, bio, and link.

Domain

Give a topic a friendly global name.

  • Domain — the name you want (e.g. mymap). Anyone can then load the topic by that name instead of the 0.0.x id.
  • Check Domain Availability — asks the domain registry: "no one uses this domain" means it's free to claim; otherwise it shows how much time is left on the current registration.
  • Add 28 days to domain — registers the domain for the topic (or renews an existing one) for 28 days. Costs 1 USDC (token 0.0.456858 — tap the id to copy it).
  • After registering, paste the domain into Load and it opens the topic directly.

Load

Find and read any topic.

  • Load messages from a topic ID or a linked domain. An account id opens that person's bio, the same card as tapping their profile picture.
  • Stacked topics (multiple IDs on one domain) load together, with the creator's names.
  • Options — filter by blocked users, a date/time range, or specific users.
  • Saved on this phone — a topic you load stays here. The next load fetches only new messages. Names, pictures, links, and bios stay here too, and the next open fetches only accounts that changed.

Create Topic

Start a new space.

  • Create a new topic ID or a new key pair.
  • New topics must be stacked: TOOLBAR → Stack topic IDs.
  • Admins — who can change this topic's rules later. Keep your private key safe to do so.
  • Your keys also power E2EE Chat: public locks messages, private unlocks them.

Model Sharing & Rules

Share locations with NFT holders.

  • Domain/Topic ID — where the data is stored.
  • Model sharing — choose which NFT holders can share their location (top-right corner).
  • Model size — size multiplier per NFT. Example: VIP NFT at 2× → 2× bigger model.
  • Topic chat — only messages from users with the required NFT are shown.
  • Markers — the NFT required to post markers, and how many each owned NFT allows. Several marker rules can be set. Setting the same NFT again uses the latest count.
  • Polygons — the NFT, how many polygons each owned NFT allows, and the max size. Several polygon rules can be set. Setting the same NFT again uses the latest count and size.
  • Remove uses the NFT ID in the field and drops only that rule. Each loaded marker or polygon rule also has an ✕, which sends that same remove message for its NFT.
  • Enter a Domain/Topic ID and press Load Topic Rules to read the current rules.

Update Topic

Edit your topic's rules and fees.

  • Domain/Topic ID — the topic to edit.
  • Private key — signs and approves the change.
  • Admins — who can set this topic's rules. Load memo shows the current memo before you change it.
  • Update bio and Topic name — Load bio and Load name fill the current text before you change it.
  • Optional fee — make users pay per message posted.
  • Set amount — the fee per message.
  • Token ID — the Hedera token received as payment.
  • Royalty account — where the payments go.

Topic Chat

Read and write public messages.

  • Domain/Topic ID — the topic to read and write.
  • Load — fetch its messages.
  • Options — filter by blocked users, a date/time range, or specific users.
  • Go to the top — back to the start of the chat.
  • Submit Message — needs a Domain/Topic ID; max 256 characters.

E2EE Chat

Private, end-to-end encrypted messages.

  • Domain/Topic ID — the topic to read and write.
  • Load — fetches messages; your private key / password unlocks them.
  • Options — filter by blocked users, a date/time range, or specific users.
  • Pin — as admin, pin your public key so only you can unlock messages.
  • Go to the top — back to the start of the chat.
  • Submit Message — needs a Domain/Topic ID; max 256 characters.
